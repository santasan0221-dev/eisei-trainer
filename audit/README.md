# 教材校閲台帳
- `audit/review-ledger.json`: 監査経緯を残す独立した台帳。最初の3問のみ公式法令との一次照合記録がある。
- `一次照合` は監査開始の記録で、第三者専門家の「校閲済」を意味しない。
- 各設問の根拠条文、法令施行日、選択肢ごとの正誤説明、レビュー担当者、二次承認が揃うまで `approved: false` のまま。
- 台帳はアプリの解答データや教材公開フラグに自動反映しない。
- 公式法令: https://laws.e-gov.go.jp/law/347M50002000032/20260101_507M60000100097/
- 教材の一時公開は学習機能の試験に限定。商用化は214問を監査し直してから。
