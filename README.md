# 衛生管理者 合格トレーナー PRO — GitHub Pages版

ユーザー提供の修正版HTMLをベースにした静的Webアプリです。元の問題データと採点ロジックを維持しています。

## GitHub Pagesで公開
1. GitHubで新しい **Public** リポジトリ `eisei-trainer` を作成。
2. このフォルダの `index.html`、`.nojekyll`、`README.md` をリポジトリ直下にアップロードしてコミット。
3. リポジトリの **Settings → Pages → Build and deployment → Source: Deploy from a branch**、**Branch: main / (root)** を選んで保存。
4. Pagesに表示されたURLで表示と回答操作を確認。

## ローカル動作確認
`index.html` をChrome等で開くだけで演習できます。履歴はそのブラウザのlocalStorageに保存されます。

## 公開前に必ず確認
- 設問・選択肢・解説の全件校閲と出典整備
- 関係法令の施行日・適用範囲および第一種の5区分別の網羅性
- 模擬試験の44問抽出、配点、合格判定の独立したQA
- 教材中の反復バリエーションの量と誤解を招く表現
- 無料利用の告知、プライバシー説明、免責、問い合わせ先

GitHub Pagesの静的配信では学習履歴は端末間で同期されず、有料教材や秘密の正答データを保護できません。
